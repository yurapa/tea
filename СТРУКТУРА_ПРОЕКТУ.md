# TeaVibe Store - Структура Проекту

## Загальний Опис

Повнофункціональний **E-commerce застосунок** для продажу чаю, побудований на сучасних веб-технологіях.

---

## Основний Стек Технологій

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **PostgreSQL** + **Prisma ORM**
- **NextAuth v5** (автентифікація)
- **Tailwind CSS** + **ShadCN UI**
- **React Hook Form** + **Zod** (валідація)
- **PayPal** + **Stripe** (платежі)
- **Resend** + **React Email** (email-сервіс)
- **UploadThing** (завантаження файлів)

---

## Структура Директорій

```
tea/
├── app/                    # Next.js App Router
│   ├── api/               # API маршрути (auth, webhooks, upload)
│   └── [locale]/          # Інтернаціоналізовані сторінки
│       ├── (root)/        # Публічні сторінки (магазин)
│       ├── (auth)/        # Автентифікація (вхід/реєстрація)
│       ├── user/          # Кабінет користувача
│       └── admin/         # Адмін-панель
│
├── components/            # React компоненти
│   ├── ui/               # Базові UI компоненти (ShadCN)
│   └── shared/           # Бізнес-компоненти
│
├── lib/                   # Утиліти та server actions
│   └── actions/          # Серверні дії (cart, order, product, user)
│
├── prisma/               # База даних
│   ├── schema/           # Модульна схема (User, Product, Cart, Order, Review)
│   └── migrations/       # Міграції
│
├── i18n/                 # Переклади (en, el, uk, ru)
├── email/                # Email шаблони
├── hooks/                # Custom React hooks
├── types/                # TypeScript типи
└── public/               # Статичні файли
```

## Архітектура Застосунку

### Frontend (Next.js App Router)

**Основні маршрути:**
- `/` - Головна сторінка
- `/product/[slug]` - Сторінка товару
- `/cart` - Кошик
- `/shipping-address` → `/payment-method` → `/place-order` - Процес оформлення
- `/order/[id]` - Підтвердження замовлення
- `/user/profile` - Профіль користувача
- `/admin/overview` - Адмін-панель (аналітика, товари, замовлення, користувачі)

**Міжнародна підтримка:**
- 4 мови: англійська, грецька, українська, російська
- Локалізовані URL через next-intl

### Backend (Server Actions)

**Серверні дії** (в `/lib/actions/`):
- `cart.actions.ts` - Операції з кошиком
- `order.actions.ts` - Обробка замовлень
- `product.actions.ts` - CRUD операції з товарами
- `review.actions.ts` - Відгуки на товари
- `user.actions.ts` - Управління користувачами

**Middleware:**
- Захист маршрутів (автентифікація)
- Інтернаціоналізація
- Редирект неавторизованих користувачів

### Автентифікація (NextAuth v5)

- JWT-сесії (30 днів)
- Email/пароль автентифікація
- Ролі: admin, editor, user
- Злиття гостьового кошика при вході
- Welcome emails при реєстрації

### База Даних (PostgreSQL + Prisma)

**Модулі схеми:**
- **User** - Користувачі, акаунти, сесії
- **Product** - Товари (назва, slug, категорія, зображення, ціна, рейтинг)
- **Cart** - Кошик (підтримка гостей та авторизованих користувачів)
- **Order** - Замовлення та OrderItem (деталі замовлення)
- **Review** - Відгуки з рейтингами

**Особливості:**
- UUID первинні ключі
- JSON колонки для складних даних
- Cascade deletes
- Автоматичні timestamps

## API Маршрути

- `/api/auth/[...nextauth]` - NextAuth автентифікація
- `/api/uploadthing` - Завантаження зображень
- `/api/webhooks/stripe` - Stripe webhooks для платежів

---

## Інтеграції

- **Платежі**: PayPal (sandbox/prod), Stripe, Cash on Delivery
- **Email**: Resend API + React Email шаблони
- **Файли**: UploadThing для зображень товарів
- **Аналітика**: Google Analytics + Google Tag Manager

## Налаштування Оточення

Необхідні змінні в `.env`:
- `DATABASE_URL` - PostgreSQL підключення
- `AUTH_SECRET` - NextAuth секрет
- `PAYPAL_CLIENT_ID` / `PAYPAL_APP_SECRET`
- `STRIPE_SECRET_KEY` / `STRIPE_PUBLISHABLE_KEY`
- `RESEND_API_KEY` - Email сервіс
- `UPLOADTHING_TOKEN` - Завантаження файлів
- `NEXT_PUBLIC_GOOGLE_ANALYTICS_ID`
